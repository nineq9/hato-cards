# KAWASEMI DIVE LAB E — NETWORK / DEEP

Isolated touchable experiments. Not production DIVE.

## Open locally

From repository root:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/demos/dive-lab-e/
```

The index switches instantly among ten concepts. Each concept is also available at its own subdirectory.

## What to test

For each concept:

1. Start from the CARDS-like fixture article.
2. Enter DIVE.
3. Perform the concept's primary operation at least three times.
4. Inspect one typed relationship's PROVENANCE.
5. Use TRAIL and BACK.
6. Return with ARTICLE.
7. Open SESSION and resume.

All event/source content in the lab is synthetic fixture data and is labeled as such.

Canonical research, comparison, QA results, and top-three recommendation are recorded in `docs/labs/DIVE_LAB_E_NETWORK_DEEP.md`.

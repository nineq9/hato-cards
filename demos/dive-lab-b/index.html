EXPERIMENTAL WORKSTREAM · DIVE LAB B

PLAY / LEARNING

ゲーム・学習・収集・knowledge productsから「もう一手やりたくなる構造」だけを借り、ニュースをゲーム化せずに10種類のDIVE体験へ翻訳したtouchable labです。

このLABの共通ルール見た ≠ 理解した。UNKNOWN ≠ 失敗。HISTORY = 実際に辿ったもの。SAVED = 意図的に残したもの。
01 · PROVENANCESOURCE TRACE

出典を一段ずつ遡り、根拠が届く地点と切れる地点を残す。

 02 · UNFINISHED THREADQUESTION CHAIN

正解を当てず、「次に確かめる問い」を開いていく。

 03 · COMPLETIONCOVERAGE BOARD

理解度ではなく、実際に見た観点だけを可視化する。

 04 · COMPARECOMPARISON LENS

二つの情報源を比較軸で切り替え、差分を次の入口にする。

 05 · CHOICEDISCOVERY HAND

3つのtyped connectionから自分が追いたい1つを選ぶ。

 06 · ORDERCHRONOLOGY TABLE

時刻精度を壊さず、断片の順番を作業仮説として組む。

 07 · VERIFICATIONCLAIM PAIR

二つの主張を並べ、勝者ではなく検証ギャップを見る。

 08 · RETURN MOTIVATIONRETURN FILE

未解決の問いと「前回以降の新材料」を戻る理由にする。

 09 · CURATIONCOLLECTION SHELF

発見をユーザー自身の意図で棚へ残し、探索を資産化する。

 10 · ATTRIBUTIONACTOR VIEW

話者ごとに主張・根拠・UNKNOWNを分離して切り替える。
